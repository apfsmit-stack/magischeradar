# MagischeRadar 2.2

## Nieuw
- Meer geografische ijkpunten, waaronder Hoorn, Enkhuizen, Alkmaar en Almere.
- Lokale driehoeksinterpolatie in plaats van een landelijke gewogen gemiddelde berekening.
- Herstel van de handmatige kaartkeuze: de kaart ontvangt nu daadwerkelijk klik- en tikacties.
- Verbeterde zweef-, galop-, wandel- en springbewegingen voor de bestaande illustraties.
- Postcodeopzoeking blijft gebaseerd op de eerste vier cijfers via PDOK; exacte huisadressen worden niet opgevraagd.

## Installatie
Upload alle bestanden uit deze map naar de hoofdmap van de bestaande GitHub Pages-repository. Controleer daarna met een voorbeeldreis van 30 seconden.

## Grenzen
De kaart is een artistieke illustratie. De plaatsing is bij benadering. Buiten de gekalibreerde driehoeken wordt het dichtstbijzijnde ijkpunt gebruikt. Een echte beweging van afzonderlijke paardenbenen of vleugels vereist animatieframes of afzonderlijke beeldlagen en is in deze versie niet gerealiseerd.
